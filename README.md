### 2. นำขึ้น GitHub Pages
1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ Commit และ Push ขึ้น Repository บน GitHub:
   ```bash
   git add .
   git commit -m "Deploy Saiyok Healthcheckup Web App with Login, Group CL, Advice CJ and Delete features"
   git push origin main
   ```
2. บนหน้าเว็บ GitHub ไปที่แท็บ **Settings** ของ Repository
3. ในเมนูด้านซ้ายเลือก **Pages**
4. ในส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** (หรือ **master**) และโฟลเดอร์ **/(root)**
   - กดปุ่ม **Save**
5. รอระบบ GitHub สร้างหน้าเว็บประมาณ 1-2 นาที จะได้ URL สำหรับเข้าใช้งาน เช่น:
   `https://[username].github.io/saiyokhos-Healthcheckup/`

## 🎯 ฟังก์ชันการทำงานสำคัญ

### 1. ระบบยืนยันตัวตน (Authentication)
- มีระบบล็อกอินปลอดภัย รองรับการจำสถานะ (Session) ไม่ต้องล็อกอินซ้ำขณะใช้งาน
- เมนู Logout สำหรับออกจากระบบ

### 2. ระบบจัดกลุ่มสุขภาพ (คอลัมน์ CL) และ คำแนะนำ (คอลัมน์ CJ)
- กดปุ่ม **"ประเมิน"** ในตารางข้อมูลของเจ้าหน้าที่แต่ละคน
- เลือกกลุ่มสุขภาพ:
  - 🟢 **ปกติ**: ผลตรวจอยู่ในเกณฑ์มาตรฐาน ไม่พบโรค
  - 🟡 **เสี่ยง**: มีภาวะเสี่ยง เช่น ดัชนีมวลกายเกิน, ความดันปานกลาง
  - 🔴 **ป่วย**: ผลตรวจผิดปกติชัดเจน / เป็นโรคเรื้อรัง
- กรอกข้อความ **คำแนะนำ / ข้อควรปฏิบัติ** สำหรับเจ้าหน้าที่
- ระบบจะบันทึกลงในคอลัมน์ CL และ CJ ใน Google Sheets อัตโนมัติทันที

### 3. ระบบลบข้อมูลเจ้าหน้าที่ (Delete)
- กดปุ่ม **"ลบ"** (รูปถังขยะสีแดง) ในตาราง
- มีหน้าต่างแจ้งเตือนยืนยันความปลอดภัยเพื่อป้องกันการลบโดยไม่ตั้งใจ
- เมื่อยืนยัน แถวข้อมูลดังกล่าวจะถูกลบออกจาก Google Sheets ทันที

### 4. พิมพ์แบบประเมินผลการตรวจสุขภาพ (A4 Print-ready)
- กดปุ่ม **"พิมพ์"** เพื่อเปิดแบบประเมินมาตรฐานโรงพยาบาลไทรโยค
- ระบบจะวิเคราะห์ผลและติ๊กเลือกเครื่องหมายถูก `( ✓ )` และ `[ ✓ ]` แบบเวกเตอร์ 100% คมชัดสูง ไม่เลือนราง พร้อมคำแนะนำที่แพทย์หรือพยาบาลได้ระบุไว้
- สามารถคลิกเปลี่ยนตัวเลือกบนหน้าจอก่อนสั่งพิมพ์ได้ทันที

### 5. ส่งออกข้อมูลเป็น Excel (.xlsx)
- มีปุ่มส่งออกข้อมูลตามเงื่อนไขการค้นหา/ตัวกรอง ออกมาเป็นไฟล์สเปรดชีต Excel ทันที
